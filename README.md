# Québécois Speaking Drill

An installable web app (PWA) for practising 200 colloquial Québécois phrases out loud,
plus 8 short two-voice stories for listening practice. Works offline after the first visit.

Install on iPhone: open the GitHub Pages address in Safari, then Share › Add to Home Screen.

Audio was generated with Microsoft Edge's French (Canada) neural voices (Sylvie and Antoine).
